# Outputアルゴリズム設計前提

## 概要

Output アルゴリズムは、物理計算結果を可視化・比較しやすい形へ整える責務を持つ。ここでは、軸の扱い方、図表 DTO の設計、Export との分離方針を記載する。

## 参照軸の扱い

forward の図表生成では、`slip`, `frequency`, `input_line_voltage` を参照軸として扱う。`frequency` と `input_line_voltage` の組み合わせごとに条件を固定し、slip 方向の 1 次元スライスを取り出す。

slip は 0〜1 の範囲を取りうるが、入力データが全範囲を覆う必要はない。補間や外挿が必要になった場合は、Output アルゴリズムの内部に直接埋め込まず、補間用の独立コンポーネントとして扱う。

## slip 軸と出力比軸

slip 軸は、回路モデルの生の計算結果を確認するのに向いている。一方、出力比軸は、カタログや運用上の性能評価と比較しやすい。

Output では両方を生成する。

- slip 軸: slip に対する出力、入力電流、力率、効率。
- 出力比軸: 定格出力に対する比率を x 軸とし、回転数、電流率、効率、力率を並べる。

同じ出力比を複数の slip が満たす場合は、小スリップ側を代表点として扱う。高度な選択条件が必要になった場合は、代表点選択を Strategy として切り出す。

## カタログ比較

カタログ性能カーブは、シミュレーション結果と同じ軸へ変換して重ねる。これにより、パラメータ推定やモデル妥当性の確認で、どの領域にズレが残っているかを視覚的に確認できる。

比較では、参照面と単位を揃えることを優先する。カタログ値そのものが自己無矛盾でない場合があるため、完全一致を前提にした評価は避ける。

## Output と Export の分離

Output アルゴリズムは、図表やテーブルの「定義 DTO」を生成するところまでを責務とする。具体的な描画ライブラリ、保存形式、保存先の選択は Export または上位層に寄せる。

この分離により、計算結果の整形ロジックを保ったまま、matplotlib、CSV、JSON、Web 表示などの出力方式を差し替えられる。
