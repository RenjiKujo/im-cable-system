# Outputアルゴリズムテスト方針

## 概要

Output アルゴリズムのテストでは、`ItmDto` から図表 DTO が設計どおりに構築されることを検証する。描画結果の見た目そのものではなく、DTO の構造、軸、系列、例外なく描画へ渡せることを主に確認する。

## 主な観点

- `FigureBuildingOrchestrator` が、生成可能な図表 DTO を `OutputFiguresDto` にまとめること。
- slip 軸図表で、x 軸と各 y 系列の長さ・単位・対応関係が崩れないこと。
- 出力比軸図表で、定格値を使った出力比・電流率の計算が一貫していること。
- カタログ性能カーブがある場合、対象 IM シリーズに対応する図表 DTO が生成されること。
- カタログ性能カーブがない場合でも、シミュレーション由来の図表生成が継続できること。
- Export 側は、`OutputDto` を受け取って例外なくグラフ生成へ進めることを smoke として確認すること。

## 今後の拡張

テーブル DTO やファイル出力形式を追加する場合は、列定義、単位、行データ、出力形式ごとの変換を個別に検証する。Processor 層を含む統合テストでは、`ItmDto` 群から `OutputDto`、必要に応じて Export までの疎通を確認する。
