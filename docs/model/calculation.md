# 等価回路の計算の流れ

この文書は、等価回路の上で物理量がどの順で決まるかを書く。クラス構成や DTO の受け渡しは書かない。

前提として、スリップ $s$・周波数 $f$・入力線間電圧 $\dot{V}_{LL}$ は与件である（順計算）。この 3 つが決まれば、以下の 4 段を順に 1 回ずつ通るだけで全物理量が決まる。上流の段は下流の結果を参照しない。唯一の例外が電流依存モデルで、この場合だけ段 2 の結果を段 1 へ差し戻して繰り返す。

```mermaid
flowchart LR
  immittance[1. イミタンス]
  vi[2. 電圧・電流]
  power[3. 電力]
  characteristic[4. 特性値]

  immittance --> vi --> power --> characteristic
  vi -. 電流依存モデルのみ:収束まで差し戻し .-> immittance
```

## 1. イミタンス

各要素の R/L（推定対象の基準値）に、モデル種別ごとの補正を掛けて、その動作点でのインピーダンス／アドミタンスを決める。

- **ケーブル導体**: 単位長 R'/L' に導体モデルの補正を掛け、区間長を掛けて π 型区間のインピーダンス $\dot{Z}_c$ にする。
- **IM 一次**: 直列インピーダンス $\dot{Z}_1 = R_1 + \mathrm{j}X_1$。
- **IM 励磁**: 並列アドミタンス $\dot{Y}_m$。
- **IM 二次**: 負荷支路 $R_2(1-s)/s$ を含む。二重かごでは内かご・外かごを独立した二次枝として計算し、枝アドミタンスを並列合成して等価二次にする。

補正が何に依存するか（$s$ か $|\dot{I}|$ か $f$ か）は**モデル種別だけ**で決まる。各種別の式・記号・YAML キーは [equations/index.md](./equations/index.md) の三者対応表から辿る。

摩擦・風損と漂遊負荷損はイミタンスを持たないため、この段には現れない（段 3 で効く）。

## 2. 電圧・電流

電源側から負荷側へ向かって解く。**ケーブル → IM** の順である。

1. ケーブル区間を解き、送電端から受電端（IM 端子）までの電圧降下と各部電流 $\dot{V}$, $\dot{I}$ を得る。
2. IM 端子電圧を入力として IM 内部を解き、一次電流・励磁電流・二次電流に分配する。

段 1 で確定したイミタンスだけを使うため、ここで係数の再計算は起きない。

## 3. 電力

段 2 の $\dot{V}$, $\dot{I}$ から複素電力 $\dot{S} = \dot{V}\dot{I}^*$ を求める。ここでも **ケーブル → IM** の順である。

軸出力はこの段で確定する。二次負荷支路の電力から、イミタンスを持たない 2 つの損失を差し引く。

- 摩擦・風損: [equations/im_friction_windage.md](./equations/im_friction_windage.md)
- 漂遊負荷損: [equations/im_stray_load.md](./equations/im_stray_load.md)

両損失とも有効電力のみを持ち、銘牌値が 3 相合計であるため損失も 3 相合計で出る。二次負荷支路電力から両者を減算した残りが軸出力である。

## 4. 特性値

段 3 の電力から、**回転速度 → トルク**の順に求め、その後に効率を求める。回転速度→トルクは依存関係上の順序である（トルクは回転速度を要求する）。効率は段 3 の電力だけから求まり、他の特性値には依存しないが、実装では本段の最後に計算する。

- **回転速度**: 同期速度 $n_s = 120f/p$（$p$ は極数）から $n = (1-s)\,n_s$。
- **トルク**: 軸出力を角速度で割る。角速度が極小の要素はトルクを定義できないため NaN になる。
- **効率**: 有効電力の**大きさ**の比 $|P_\mathrm{out}| / |P_\mathrm{in}|$ を、系全体・IM・ケーブルの 3 種について求める。絶対値で評価するのは、電流の向きの定義により有効電力が負になり得るため。入出力で符号が反転している場合（逆潮流の可能性）は計算を続行したうえで警告を出す。

力率は本段では持たず、必要な箇所で $\mathrm{Re}(\dot{S})/|\dot{S}|$ として求める（[curve_fitting_consistency.md](./curve_fitting_consistency.md) の残差 4 量など）。

## 電流依存モデルの反復

補正が $|\dot{I}|$ に依存するモデル種別（`CURRENT_DEPENDENT_*`）を 1 つでも含む場合、段 1 は段 2 の結果を必要とするため、上の一方向の流れが閉じない。これを次のように解く。

1. **初回**: 電流が未知なのでゼロ電流として段 1 を実行する（$r_I = 0$）。
2. 段 2 を実行して電流を得る。
3. その電流を段 1 へ差し戻し、イミタンスを作り直す。
4. 電流の相対変化が閾値未満になるまで 2〜3 を繰り返す。

反復するのは**段 1 と段 2 だけ**である。段 3・段 4 は収束後に 1 回だけ実行する（電力・特性値はイミタンス構築へ戻らないため、反復に含める意味がない）。

反復上限・収束閾値・収束基準（線電流・相電流・マージ後電流のいずれを見るか）は設定値である。電流依存モデルを含まない場合は反復せず、4 段を 1 回通して終わる。

## EstimateParams からの使われ方

パラメータ推定は、上の順計算を**目的関数の中で繰り返し呼ぶ**。

1. 推定対象（R/L とモデル係数）の試行値を等価回路に埋め込む。
2. カタログのスリップ点それぞれについて上の 4 段を通し、電流・電力・力率・効率の 4 量を得る。
3. カタログ曲線との残差を計算する。
4. 残差が小さくなるよう試行値を更新し、1 へ戻る。

順計算そのものは推定用に変わらない。変わるのは「誰が入力の R/L と係数を決めるか」だけで、forward では入力ファイル、推定では最適化器が決める。

残差の正規化・重み・カタログ 4 量の扱いは [curve_fitting_consistency.md](./curve_fitting_consistency.md)。実装の入口は [architecture/algorithm/execute/0_overview.md](../architecture/algorithm/execute/0_overview.md)。
